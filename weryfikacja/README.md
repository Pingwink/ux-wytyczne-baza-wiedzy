1. **Zgodność merytoryczna i liczbowa** ze źródłem pierwotnym (wartości progowe WCAG 2.2, progi Core Web Vitals, statystyki z badań NN/g, Baymard, WebAIM Million 2025/2026, Hoobera, GDS, Deque, SUS).

3. **Poprawność adresów URL** – sprawdzenie istnienia docelowych stron i korekta nieaktualnych lub nieprecyzyjnych slugów bezpośrednio w plikach dokumentacji.
